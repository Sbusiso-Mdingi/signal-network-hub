Policies and notices

The practical rules for using and contacting Sequrin.

These notices describe the current public website. Separate legal, privacy, security and contractual approval is required before any future customer-controlled claims evaluation.

Last updated 22 August 2026

01

Privacy

The current public website is informational and has no contact form, visitor account, advertising tracker or non-essential analytics in the reviewed build. Hosting and network providers may process routine request and security data.

Sequrin currently uses synthetic and development data in product demonstrations. Read the full website Privacy Notice.

02

Email

Use info@sequrin.com for ordinary business, privacy, PAIA, legal and security enquiries. Do not send patient records, member information, claims, clinical records, passwords or other sensitive material unless Sequrin has provided a secure authorised method.

03

Product information and public claims

This website describes Sequrin's current product capabilities and longer-term direction. Interface views and public material do not promise a specific customer deployment, regulatory approval, certification, detection accuracy or financial outcome. Read the full website terms.

04

Cookies and tracking

The reviewed build does not set advertising cookies or run non-essential analytics. Read the cookie and tracking statement.

05

Application sign in

The Sign in link takes invited, authorised users to the separately hosted Sequrin application. The public website does not ask visitors to enter workspace credentials.
